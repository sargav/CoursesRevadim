## מבנה הקבצים

- `style.css` – עיצוב משותף לכל העמודים (איפוס בסיסי וכפתור "לכל הקורסים"). שאר העיצוב של כל עמוד נמצא בתוך הקובץ שלו, בתגית `<style>`.
- `logo.png` – הלוגו של רבדים.
- `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` – האייקון של הלשונית ושל מסך הבית בטלפון.
- `sitemap.xml`, `robots.txt` – מפת האתר לגוגל.

## איך מעדכנים

האתר בנוי מקבצי HTML רגילים, בלי שלב בנייה.
כל שינוי שנכנס לענף `main` עולה אוטומטית ל-Render תוך דקה-שתיים.

**הוספת קורס חדש**
1. יוצרים קובץ HTML חדש. שם הקובץ באותיות קטנות באנגלית, עם מקף בין מילים (למשל `new-course.html`).
2. מוסיפים קישור אליו בדף הבית (`index.html`).
3. מוסיפים אותו ל-`sitemap.xml`.

**מעבר לדומיין חדש:** צריך להחליף את הכתובת `racheligrinbaum.onrender.com` בקבצים `sitemap.xml` ו-`robots.txt`, ובקוד ה-Schema (`application/ld+json`) שבדף הבית ובעמודי הקורסים.
