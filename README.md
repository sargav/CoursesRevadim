## מבנה הקבצים

- `style.css` – עיצוב משותף לכל העמודים (איפוס בסיסי וכפתור "לכל הקורסים"). שאר העיצוב של כל עמוד נמצא בתוך הקובץ שלו, בתגית `<style>`.
- `logo.png` – הלוגו של רבדים.
- `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` – האייקון של הלשונית ושל מסך הבית בטלפון.
- `sitemap.xml`, `robots.txt` – מפת האתר לגוגל.
